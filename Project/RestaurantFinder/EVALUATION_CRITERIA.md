# 「本当に美味しい店」の評価基準

食べログ・Google マップなどの点数を出発点にはするが、点数だけでは
拾えない要素をどう補うか、をリサーチしたうえで整理したもの。
`src/scoring.js` の実装はこの基準をそのままロジック化している。

## 1. 点数（食べログ等）の使い方と限界

- 点数の算出ロジックは非公開（ブラックボックス）で、過去には点数操作・
  やらせレビューが問題になった経緯がある（カカクコムは「営業活動による
  点数操作は否定」と公式見解を出しているが、口コミ代行業者による偽レビュー
  自体は継続的に報告されている）。
  [食べログを信用しますか？ やらせ依頼の全文掲載](https://business.nikkei.com/atcl/gen/19/00087/022700025/) /
  [食べログのサクラ・やらせ口コミの事実](https://4byss.co.jp/hirakulog/tabelog-bad/)
- 点数の分布自体に偏りがあり、3.6〜3.8 付近に大半の店が集中する。
  そのため「3.5 と 3.6」のような僅差はほぼ意味を持たず、絶対値の
  横並び比較には向かない。
  [食べログの評価の仕組み](https://niigata-seo.com/restaurant/tabelog-score/)
- レビュー件数が少ないと極端な評価（1件の大絶賛/大批判）で平均が
  簡単に振れる。**件数が十分（目安100件以上）になって初めて「平均的な
  評価」に近づく**という指摘がある。
  [食べログで美味しい店を見分ける方法](https://note.com/fine_otter641/n/ned4709f6268f)

→ 結論：**点数は「足切り」や「一次スクリーニング」には使えるが、
それ単体を最終評価にしない。** 件数で信頼度を重み付けし、複数の
点数源を横断して見る。

## 2. 点数だけでは拾えない、本当に効く要素

Web 上の一次情報・不正レビュー検出研究などから抽出した、点数以外に
見るべきシグナル。

| # | 要素 | 見るポイント | 根拠 |
|---|------|--------------|------|
| 1 | **レビューの一次情報性** | 具体的なメニュー名・体験談・写真が伴っているか。定型文・抽象的な絶賛のみのレビューは価値が低い | 「一次情報に裏付けられた具体的考察が信頼できる証拠」[おいしい金沢](https://note.com/oic_kanazawa/n/n3722d399d4f0) |
| 2 | **リピート言及** | 「また来た」「〇回目」「気づけば通っている」等の再来店に触れたレビューの比率 | 紹介・口コミ経由の客はリピート率が高い傾向 [ぐるなび通信](https://pro.gnavi.co.jp/magazine/t_res/cat_3/a_4237/) |
| 3. | **評価の分布形状** | 星5と星1に極端に二極化（U字型）していないか。不自然な急増（短期間に大量の高評価）がないか | 評価の急激な逸脱・不自然な集中はフェイクレビューの典型的シグナル [Fake Review Detection研究](https://arxiv.org/pdf/2003.00807) |
| 4 | **レビュアーの継続性・多様性** | 極端に新しいアカウントばかりからの高評価が集中していないか。地理的に無関係な地域からの投稿が混ざっていないか | Google も「別都市のアカウントが急に低評価を残す」等の異常活動を検知対象にしている [Google公式ブログ](https://blog.google/products/maps/google-maps-101-how-we-tackle-fake-and-fraudulent-contributed-content/) |
| 5 | **SNS・個人ブログでの自然な言及** | インフルエンサーの案件投稿ではなく、位置情報付き・継続的な個人の言及があるか | 友人・知人のブログ/SNS経由の来店客は常連化しやすい＝実体験の裏付けとして強い [データ分析ラボ](https://note.com/dataanalysislabo/n/ne2ec91e9c0ca) |
| 6 | **事業の継続年数** | 開業から一定年数営業し続けているか（美味しくない店は淘汰されやすい） | 一般的な飲食店の廃業率の高さを踏まえた消去法的シグナル |
| 7 | **価格帯とのバランス** | 高評価が価格の高さで「買われた」ものでないか。コスパ言及の有無 | — |
| 8 | **第三者専門媒体の評価** | ミシュラン・地元グルメ誌など、取材ベースの評価があるか | 紙媒体は取材に基づく情報量の多さで信頼性を補完できる [note: 藤田正和](https://note.com/fine_otter641/n/ned4709f6268f) |

## 3. 総合スコアの考え方（`src/scoring.js` の実装方針）

1. **信頼度補正した基礎点**：単純平均ではなく、レビュー件数に応じて
   全体平均へ引き寄せるベイズ平均（Wilson/Bayesian average）を使う。
   件数が少ない店の極端な高評価・低評価を過大評価しない。
2. **分布ペナルティ**：星1・星5比率が両方高い（二極化）場合は
   フェイクレビュー疑いとしてスコアを減点。
3. **リピート言及ボーナス**：レビュー本文に再来店を示す語（「また」
   「リピート」「〇回目」等）が含まれる比率をボーナスとして加点。
4. **一次情報ボーナス**：レビュー本文の平均文字数・具体的なメニュー
   名らしき語の出現で簡易的に「具体性」を推定し加点。
5. **異常投稿ペナルティ**：短期間に評価が急増した形跡（同日・近接日時
   に集中した大量レビュー）を検知し減点。

この5要素を重み付き合成し、0〜100の総合スコアとして出力する。
実装は `src/scoring.js` の `scoreRestaurant()` を参照。
