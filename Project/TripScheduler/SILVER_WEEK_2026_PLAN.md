# シルバーウィーク2026 旅程（大船発・9/21月〜9/23水）

## 前提条件のリサーチ

- 2026年は9/19(土)〜9/23(水・秋分の日)が**11年ぶりのカレンダー通り5連休**。
  9/21(月)は敬老の日、9/22(火)は「国民の休日」（敬老の日と秋分の日に
  挟まれた祝日）、9/23(水)は秋分の日。
  [ウォーカープラス](https://www.walkerplus.com/article/1438615/)
- 交通の混雑ピークは**9/19(土)午前の下り**と**9/23(水)午後〜夜の上り**。
  9/21・22は移動のピークからは外れる見込み。
  [trip.com](https://jp.trip.com/blog/silver-week-travel/)
- → **9/23は午前中に活動を切り上げ、午後は早めに移動を終える**のが
  行程の基本方針。

## 行き先選定の考え方（EVALUATION_CRITERIA.md の思想を流用）

食べログ的な「有名観光地ランキング」だけで選ぶと、大仏・小町通り・江ノ島は
5連休中は身動きが取れないほど混む。そこで、

1. 大船から近い（電車1〜2駅／徒歩圏）
2. 全国区の超定番ではないが、地元で評価が定着している
3. 敷地が広く人が分散する、または元々の来場者が少なめ

という基準でスポットを選定した。北鎌倉の寺社群・逗子葉山方面・大船周辺の
寺社は、いずれも鎌倉大仏や江ノ島に比べて分散傾向があるとされる。

Wifi・電源のあるカフェ／コワーキングは大船駅前に複数あり、休憩や
軽い作業に使える（NEKTON大船・どこがく・快活CLUB大船駅前店など）。
[Workship MAGAZINE](https://goworkship.com/magazine/ofune-cafe-dengen-wifi/) /
[sharemap](https://sharemap.jp/spots/22077)

**ホテルについて**：直前の予約になるため、5連休中は大船・北鎌倉・
大船駅周辺のビジネスホテルの空室が急速に埋まる可能性が高い。
本プランでは大船駅徒歩圏を想定しているが、**今日〜明日中に空室を
確認・予約すること**を強く推奨する（詳細は本ドキュメント末尾）。

## Day 1｜9/21(月・敬老の日) 北鎌倉コース

| 時間 | 内容 | メモ |
|---|---|---|
| 09:00-10:30 | 大船フラワーセンター散策 | 大船駅から徒歩16分。ピークシーズンでも他の定番より空いている穴場 |
| 10:30-11:00 | 大船駅へ戻り、JR横須賀線で北鎌倉へ | 1駅・約3分 |
| 11:00-13:00 | 北鎌倉の寺社めぐり（円覚寺→東慶寺→浄智寺） | 敷地が広く分散するため大仏・小町通りほど混まない |
| 13:00-14:00 | 北鎌倉周辺で昼食 | 静かな時間帯を狙うなら13時台は比較的空く |
| 14:00-15:30 | 建長寺（北鎌倉から徒歩約15分） | 鎌倉五山第一位。広い境内で滞留しにくい |
| 15:30-16:30 | 大船へ戻り、コワーキング／カフェで休憩 | NEKTON大船・どこがく・encafe等 |
| 17:00〜 | 大船周辺でホテルチェックイン・夕食 | |

## 宿泊・予約についての注意（要アクション）

- 11年ぶりの5連休のため、**大船・鎌倉エリアのホテル空室は今夜〜明朝には
  かなり埋まる可能性が高い**。可能であれば今日中に予約を確定させること。
- 以前作成した [`Project/Maps`](../Maps/) のホテル空室検索の仕組み
  （楽天トラベルAPI連携）を使えば、大船駅周辺を中心に空室のある宿を
  効率的に探せる。API キーがあれば `Project/Maps` をそのまま使って
  検索範囲を大船駅周辺に絞って確認するのが早い。
- 本ドキュメントの行程・店舗情報は一般的な下調べに基づく提案であり、
  **実際の営業時間・定休日・混雑状況は出発前に必ず最新情報を確認**
  すること（祝日でも休みの寺社・店舗がある）。
