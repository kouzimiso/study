# シルバーウィーク2026 旅程（大船在住・9/21月〜9/23水）

## 前提の見直し

大船在住なので、大船周辺（北鎌倉・逗子葉山など）を巡る前回プランではなく、
**車で日帰り圏の「足を延ばす」行き先**を選んだ。選定は
`src/selectRoutes.js` の自動選定ロジックを使い、`data/routes.json` の
ルートカタログから「未訪問優先・混雑リスク medium 以下・訪れるエリアが
偏らない」という条件で3ルートを選んでいる（詳しいロジックは
[`DESIGN.md`](./DESIGN.md) 参照）。

```bash
node -e "
const { selectRoutesForTrip } = require('./src/selectRoutes');
const routes = require('./data/routes.json');
const visitHistory = require('./data/visitHistory.json');
console.log(selectRoutesForTrip(routes, visitHistory, 3, {
  today: new Date('2026-09-20'),
  excludeIds: ['atsugi-onsenkyo'], // 温泉ルートが重複しないよう、今回は湯河原を優先
}));
"
```

→ **真鶴・湯河原（西）／三浦半島西海岸（南西）／ヤビツ峠・宮ヶ瀬（北西）**
の3方向を選定。海・山・温泉のバリエーションが出るよう組んだ。

## 交通の混雑ピークについて

2026年は9/19(土)〜9/23(水)が11年ぶりの5連休。混雑ピークは
**9/19(土)午前の下り**と**9/23(水)午後〜夜の上り**と予想されている。
→ 9/23は午前中心の行程にし、午後早めに帰宅する。
[ウォーカープラス](https://www.walkerplus.com/article/1438615/) /
[trip.com](https://jp.trip.com/blog/silver-week-travel/)

三崎・城ヶ島（マグロ・灯台）と箱根は、今回は見送った
（`data/routes.json` に候補として保持済み。crowdRisk: high）。
特に三崎・城ヶ島は「連休中は道路も駐車場も激込み」との報告があるため、
次に行くなら平日か早朝出発が前提になる。

## 次回に向けて（訪問記録）

この旅程を実行したら、`data/visitHistory.json` に3ルート分の訪問日を
追記しておくこと。次回シルバーウィーク等に同じ選定ロジックを走らせると、
今回行った3ルート（真鶴湯河原・三浦半島西海岸・ヤビツ峠宮ヶ瀬）は
経過日数が浅くなるため後回しになり、未訪問のあつぎ温泉郷・鶴巻温泉・
大磯二宮などが優先的に提案される。

```json
[
  { "routeId": "manazuru-yugawara", "visitedOn": "2026-09-21" },
  { "routeId": "miura-west-coast", "visitedOn": "2026-09-22" },
  { "routeId": "yabitsu-miyagase", "visitedOn": "2026-09-23" }
]
```
